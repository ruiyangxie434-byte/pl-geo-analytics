# Player Lab 指标与百分位口径

## 功能范围

`v0.7.0` 新增 `/players` 球员数据中心和 `/players/[slug]` 球员详情页，形成以下路径：

```text
球员榜 → 搜索/筛选/排序 → 双人雷达 → Agent 对比
     └→ 球员详情 → 累计数据/每90指标/百分位
```

当前球员池仍是 12 名演示样例，不是完整英超阵容库。

## 每 90 分钟计算

所有衍生指标由 FastAPI 后端统一计算：

```text
每90分钟指标 = 累计指标 × 90 ÷ 出场分钟
```

分钟数为 0 或原始值缺失时返回 `0.0`，其余结果保留两位小数。前端只负责显示，不重复计算业务指标。

当前包含：

- 进球、助攻、射门；
- 关键传球；
- 抢断、拦截；
- 预期进球（xG）。

## 样本门槛

球员中心默认使用 `450` 分钟门槛，也支持切换至 `1800` 或 `2700` 分钟。改变门槛后，后端会重新确定合格球员池并计算百分位。

## 百分位范围

雷达图优先把球员与同位置合格样例比较：

1. 同位置合格样例不少于 3 人：返回 `position_sample`。
2. 同位置合格样例少于 3 人：回退全部合格样例，返回 `all_sample_players`。
3. API 同时返回 `peer_count`，前端在每张球员卡片上显示真实比较人数。

百分位只描述当前小型样例池内的相对位置，不能解释为完整英超排名或绝对能力评分。

## API

```text
GET /api/players
GET /api/players/{slug}
```

列表接口支持：

- `season`
- `minimum_minutes`
- `query`
- `position`
- `club_slug`
- `sort_by` / `order`
- `limit` / `offset`

自动化测试覆盖指标换算、筛选、排序、分页、详情、位置样本回退和参数错误。
