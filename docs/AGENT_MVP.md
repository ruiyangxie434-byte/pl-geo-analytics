# PitchMind Hybrid Agent

## 本阶段目标

把原来的英超数据展示平台升级为可以完成一条足球分析任务的垂直 Agent：

```text
用户任务
  → 识别两名球员和分析重点
  → 查询赛季数据
  → 统一换算每90分钟指标
  → 在样例球员池中计算百分位
  → 按任务动态加权
  → 输出证据、建议和结论边界
  → 千问增强表达或本地安全回退
```

## 为什么它不只是聊天框

Agent 的关键数值不是由自然语言模型猜测，而是由后端工具计算：

| 步骤 | 工具 | 责任 |
| --- | --- | --- |
| 1 | `intent_router` | 识别球员比较任务与分析重点 |
| 2 | `player_stats_query` | 从 SQLite 读取指定赛季记录 |
| 3 | `per90_calculator` | 换算每90分钟指标与样例百分位 |
| 4 | `evidence_ranker` | 按任务权重排序证据并形成建议 |
| 5 | `qwen_grounded_narrative` / `local_narrative` | 基于既有证据组织最终回答 |

前端会把这五步执行轨迹直接展示出来，便于比赛评委检查“规划—工具调用—结果”
是否形成闭环。

## 当前能力边界

- 当前仅支持双球员比较。
- 当前样例为 6 支球队、12 名球员，不是完整实时英超数据库。
- 抢断和拦截只能作为防守参与度代理指标，不能完整代表真实压迫质量。
- 千问只负责回答表达，当前尚未让模型自主选择和执行函数。
- 规则引擎保证离线演示稳定，但还不具备开放式连续对话能力。

## 下一阶段

在现有千问增强回答层之上加入真实函数调用，同时保持数值工具不变：

1. 千问解析更开放的自然语言任务并自主选择工具。
2. 工具返回结构化数据和计算结果。
3. 千问继续只基于工具结果组织球探报告，不直接编造指标。
4. 保存用户的球队、位置和战术偏好，用于后续追问。
5. 没有密钥或模型调用失败时，自动退回当前本地规则引擎。
