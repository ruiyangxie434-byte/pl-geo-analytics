# Stage 3 Agent sample data

阶段 2 的初始化数据直接维护在
`backend/app/database/seed.py`，所有记录均使用
`source_kind=sample`。

它的用途是：

- 验证球队、球员、赛季统计与积分榜之间的关系。
- 验证球场经纬度可以被地图接口读取。
- 为前端加载、错误、选择和表格交互提供小型数据集。
- 为 Agent 的工具调用、每90分钟换算、动态权重和证据链提供稳定输入。
- 让自动化测试在无网络环境下稳定运行。

这些记录不是实时数据源，也不应用于正式统计结论。球队与球场字段用于结构演示；
积分榜为 2024-25 赛季 6 队切片；球员赛季指标属于开发样例。阶段 3B
接入地图前，应继续保留这一小型样例；接入完整数据源后，需为每个数据文件补充来源、
获取日期、许可证和清洗说明。
